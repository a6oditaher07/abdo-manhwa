# ABDO MANHWA

تطبيق أندرويد كامل (Kotlin + Jetpack Compose + Material 3) لقراءة المانهوا محلياً بدون إنترنت، بدون حسابات، وبدون إعلانات.

## طريقة التشغيل في Android Studio

1. افتح **Android Studio** (يُفضّل أحدث إصدار Hedgehog/Iguana أو أحدث).
2. اختر **Open** ثم حدّد مجلد المشروع `ABDOMANHWA` (المجلد الذي يحتوي على `settings.gradle.kts`).
3. انتظر حتى ينتهي **Gradle Sync** تلقائياً (أول مرة قد تستغرق بضع دقائق لتحميل المكتبات).
4. وصّل هاتفاً حقيقياً (وضع المطوّر + USB Debugging مفعّلان) أو شغّل محاكي Android بنسخة 8.0 (API 26) فأعلى.
5. اضغط زر **Run ▶** (أو Shift+F10) لتثبيت التطبيق وتشغيله مباشرة.

> الحد الأدنى للنظام المطلوب: **Android 8.0 (API 26)**. لا يطلب التطبيق أي إذن إنترنت.

## تصدير ملف APK

### APK سريع للتجربة الشخصية (غير موقّع رسمياً - Debug)
1. من القائمة: **Build → Build APK(s)**.
2. بعد الانتهاء تظهر رسالة أسفل الشاشة فيها رابط **locate** يفتح مجلد:
   `app/build/outputs/apk/debug/app-debug.apk`
3. انقل هذا الملف لهاتفك وثبّته مباشرة (فعّل "تثبيت من مصادر غير معروفة" إن طُلب).

### APK موقّع للاستخدام الدائم (Release)
1. من القائمة: **Build → Generate Signed Bundle / APK**.
2. اختر **APK** ثم **Next**.
3. أنشئ **Key store** جديد (أول مرة فقط) عبر **Create new...** واملأ البيانات المطلوبة، احفظ ملف الـ keystore في مكان آمن.
4. اختر **release**، فعّل **V1 + V2 Signature**، ثم **Finish**.
5. الملف النهائي سيكون في:
   `app/build/outputs/apk/release/app-release.apk`

## أهم المزايا المطبّقة

- **المكتبة**: شبكة بطاقتين/ثلاث بالصف، بحث، حالة "مواصلة/بداية القراءة"، شريط تقدّم، ضغط مطوّل (تعديل/حذف/إضافة فصول)، شاشة فارغة أنيقة.
- **إضافة مانهوا**: اسم + نبذة + صورة غلاف (SAF) + اختيار فصول HTML متعددة مع ترتيب طبيعي (2 قبل 10)، إعادة ترتيب يدوي، حذف قبل التأكيد، شريط تقدّم أثناء النسخ.
- **القارئ**: وضع شاشة كاملة غامر، WebView بتمرير عمودي متواصل وتكبير بإصبعين، شريط تحكم علوي/سفلي يظهر بالضغط على المنتصف فقط، سطوع داخلي، وضع راحة العين، إبقاء الشاشة مضاءة، قفل الاتجاه، حفظ تلقائي لموضع القراءة، بطاقة "الفصل التالي" عند الانتهاء.
- **التخزين**: كل الصور والفصول تُنسخ لمساحة التطبيق الداخلية (لا أذونات تخزين إضافية)، وقاعدة بيانات Room تربط كل شيء.
- **بدون إنترنت بالكامل**: لا إذن `INTERNET` في الـ Manifest، ومنع صريح لأي اتصال شبكة (`usesCleartextTraffic=false`).

## ملاحظة حول التحميل الأول في Android Studio

أول فتح للمشروع يحتاج اتصال إنترنت لمرة واحدة لتحميل مكتبات Gradle (Room، Compose، Coil...). بعدها يعمل المشروع والتطبيق نفسه بدون إنترنت كلياً كما هو مطلوب.
